# Central de downloads InfoTech

Site independente da página comercial da MC Informática. A versão publicada fica em `https://tmc1987.github.io/infotech-app-downloads/`.

Ao publicar um novo APK, atualizar o arquivo em `downloads/` e os links, a versão, o tamanho e o SHA-256 em `index.html`. Conferir o hash local e o arquivo servido publicamente antes de compartilhar o novo endereço. Os instaladores Admin continuam exigindo autenticação no aplicativo, mas o arquivo APK desta página é público.
